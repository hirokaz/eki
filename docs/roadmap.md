## 取り扱い注意事項

- 占断的・予言的な解釈はメイン体験には入れない(別タブで分離する場合のみ可)
- 「易が現代科学を予言した」式の主張は `interpretation` ラベル付きでのみ言及
- 五行・干支は易と完全には独立体系。データを混ぜない

## 改善の流れ

1. ここに案を箇条書きで追加
2. 優先度が定まったら **issue 化**(短期は週次、中長期は月次の棚卸し)
3. 着手時に feature branch で開発 → PR → セルフレビュー → merge
