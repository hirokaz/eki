## 改善の流れ

1. ここに案を箇条書きで追加
2. 優先度が定まったら **issue 化**(短期は週次、中長期は月次の棚卸し)
3. 着手時に feature branch で開発 → PR → セルフレビュー → merge
4. 完了したらこのファイルの該当行を「完了済み」セクションに移動
